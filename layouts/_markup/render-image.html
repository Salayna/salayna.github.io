{{- /* Markdown image render hook. Resolves ![alt](src "caption") in this order: 1. a file sitting next to the page (a page bundle) — the usual case 2. assets/ 3. anything else is passed through as a plain URL (remote, or static/) Resolved raster images are resized and get real width/height, so the page does not jump as they load. SVG and GIF pass through untouched — Hugo cannot resize the first and would kill the animation on the second. */ -}} {{- $src := .Destination -}} {{- $img := false -}} {{- with .Page.Resources.GetMatch $src }}{{ $img = . }}{{ end -}} {{- if not $img }}{{ with resources.Get (strings.TrimPrefix "/" $src) }}{{ $img = . }}{{ end }}{{ end -}} {{- if not .IsBlock -}} {{- /* Inline image inside a sentence: no figure, no caption. */ -}} {{- if $img }} {{- else }}{{ end -}} {{- else -}} {{- end -}}
